# Design

## Context

Greenfield: в репозитории нет кода. Целевое железо — ESP32-C3 SuperMini
(ядро `esp32:esp32` 3.3.12, arduino-cli). Особенности платы: встроенный LED
на GPIO8 (active low), кнопка BOOT на GPIO9, strapping-пины GPIO2/8/9 —
их избегаем для периферии. Motivation — см. proposal.md.

## Goals / Non-Goals

**Goals:**
- Модульная структура скетча: `firmware.ino` — только оркестрация, логика в
  отдельных модулях (.h/.cpp) — modes, display, sensors, signaling, settings,
  net.
- Неблокирующий cooperative-loop: у каждого модуля `tick()` на millis(),
  без `delay()` в рабочем коде.
- Вертикальный срез, проверяемый на железе: boot → Wi-Fi → NTP → экран
  ожидания → вызов/сон.

**Non-Goals:**
- Веб-админка (HTTP-сервер) — отдельное изменение; здесь только механизм
  настроек.
- Telegram-бот и пульт — отдельные изменения. Тестовый триггер вызова —
  команды через Serial.
- ESP32 light/deep sleep: «режим сна» — это выключение дисплея и индикаторов,
  MCU продолжает работать и держит Wi-Fi (иначе утренний выход из сна и
  команды невозможны).

## Decisions

### Распиновка (ESP32-C3 SuperMini)

| Функция | GPIO | Примечание |
|---|---|---|
| I2C SDA | 4 | свободный пин, вне strapping |
| I2C SCL | 5 | дефолт ядра 8/9 не годится: 8 — onboard LED, 9 — BOOT |
| Кнопка | 10 | `INPUT_PULLUP`, замыкание на GND |
| Баззер (активный) | 3 | через транзистор, high = звук |
| Светодиод внешний | 7 | индикатор вызова/предупреждений |
| Onboard LED | 8 | опционально для диагностики |
| UART RX/TX | 20/21 | логи и тестовые команды |

Альтернативы: I2C на дефолтных 8/9 — конфликт с onboard LED и кнопкой BOOT.
GPIO0/1/2 — strapping/системные, избегаем. Пины вынесены в `pins.h`,
финальную разводку проверить на железе.

### Время — `configTzTime()` ядра вместо библиотеки NTPClient

В ядре esp32 есть нативный SNTP: `configTzTime(tz, "pool.ntp.org")`.
Меньше зависимостей, таймзона строкой TZ — ложится в настройки.
Альтернатива: NTPClient (установлен) — лишний объект UDP-клиента без
преимуществ.

### Дисплей — U8g2, full-buffer конструктор

`U8G2_SSD1306_128X64_NONAME_F_HW_I2C` — аппаратный I2C, полный кадр-буфер
(1 КБ RAM — при 400 КБ SRAM некритично), отрисовка целиком раз в цикл
обновления без мерцания. Альтернатива page-buffer (`_1_`) — экономия RAM,
не нужна.

### Паттерн сигнализации — таблица шагов на millis()

Прерывистый писк/моргание реализованы как неблокирующий паттерн
(например 200 мс звук / 800 мс пауза, LED в том же ритме), а не tone()/delay().
Предупреждения перед отбоем — тот же механизм с однократным коротким паттерном.

### Настройки — Preferences (NVS)

Namespace `pendel`: callDurationSec, bedtime (мин от полуночи), sleepStart,
sleepEnd, tz, ssid, pass. Хранение времени суток в минутах от полуночи —
проще сравнения и окно через полуночь. Значения читаются в структуру при
старте, `save()` пишет всё атомарно.

### Тестовый триггер вызова — Serial-команды

`call 1`, `call 2`, `call both`, опционально текст. Имитирует будущий канал
команд, пока Telegram/пульта нет; интерфейс — единая функция
`triggerCall(target, message)`, которую потом дернут каналы.

## Risks / Trade-offs

- [Распиновка не проверена на реальной разводке] → пины в одном `pins.h`,
  первый прогон на железе — проверка I2C-сканером (вывести найденные адреса
  в Serial).
- [AHT20 и BMP280 в китайских модулях бывают на разных адресах] → I2C-сканер
  в диагностическом выводе, адреса в настройках/константах.
- [configTzTime без Wi-Fi не синхронизируется] → экран показывает плейсхолдеры
  до первой синхронизации, расписания отключены (по спеке).
- [NTP может подвести расписание при временной рассинхронизации] → периодический
  ресинк раз в час + проверка `time(nullptr)` на валидность.
- [Активный баззер звучит при high] → убедиться, что GPIO3 не дёргается при
  загрузке; при проблеме перенести на другой свободный пин.

## Open Questions

- Часовой пояс по умолчанию: предполагается `EET-2EEST,M3.5.0/3,M10.5.0/4`
  (Europe/Kyiv) — уточнить, настраивается параметром `tz`.
- Имена/метки детей для экрана вызова — пока «ребёнок 1»/«ребёнок 2»,
  настройка имён придёт с админкой.
