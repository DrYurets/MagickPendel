# Proposal

## Why

Репозиторий пока содержит только документацию — прошивки нет. Нужен каркас
Arduino-скетча с вертикальным срезом функциональности, который можно залить на
ESP32-C3 SuperMini и проверить на реальном железе: устройство загружается,
подключается к Wi-Fi, показывает информационный экран, обрабатывает вызов и
режим сна. Веб-админка и каналы команд (Telegram, пульт) — отдельными
изменениями поверх этого каркаса.

## What Changes

- Создание Arduino-скетча `firmware/` с модульной структурой и распиновкой
  под ESP32-C3 SuperMini.
- Ядро устройства: неблокирующий цикл, подключение к Wi-Fi с реконнектом,
  синхронизация времени по NTP, конечный автомат режимов (ожидание / вызов /
  сон).
- Экран ожидания на OLED 128×64 (SSD1306): часы, температура, влажность,
  обратный отсчёт до отбоя.
- Сигнализация вызова: прерывистый писк баззера + моргание светодиода в
  течение N секунд или до нажатия кнопки; экран вызова с текстом «кого зовут».
  В этом изменении вызов инициируется локально (тестовый триггер) — канал
  команд добавится позже.
- Опрос датчика климата AHT20 + BMP280 по I2C с периодическим обновлением.
- Отбой и сон: предупреждения за 15 и за 5 минут (звук + свет), вход в режим
  сна по расписанию (дисплей и индикаторы off), выход утром.
- Хранение настроек в NVS (Preferences): длительность вызова, время отбоя,
  окно сна, учётные данные Wi-Fi — с дефолтами и применением без перепрошивки.

## Capabilities

### New Capabilities

- `device-core`: загрузка устройства, неблокирующий главный цикл, Wi-Fi/NTP,
  конечный автомат режимов (ожидание, вызов, сон), расписание отбоя и сна
  с предупреждениями.
- `status-display`: набор экранов OLED для каждого режима и правила их
  отображения.
- `alert-signaling`: поведение при вызове — звуковой/световой паттерн,
  длительность, отмена кнопкой.
- `climate-sensing`: периодический опрос AHT20+BMP280, обработка ошибок
  датчика.
- `device-settings`: состав настраиваемых параметров, значения по умолчанию,
  сохранение в энергонезависимую память.

### Modified Capabilities

(нет — спецификаций пока не существует)

## Impact

- Новый каталог `firmware/` со скетчем и модулями.
- Зависимости (уже установлены в `~/Arduino/libraries`): U8g2,
  Adafruit AHTX0, Adafruit BMP280, NTPClient; системные WiFi/Wire/Preferences.
- Вне scope: веб-админка, Telegram-бот, пульт ESP32-C3 — следующие изменения.
- Проверка: `arduino-cli compile -b esp32:esp32:esp32c3 firmware` + прошивка
  и наблюдение на железе.
