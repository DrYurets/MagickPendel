# Spec Delta

## Purpose

HTTP-интерфейс администрирования устройства: просмотр состояния и
редактирование всех настроек через браузер без перепрошивки.

## ADDED Requirements

### Requirement: Страница админки
Устройство SHALL отдавать по HTTP веб-страницу админки, доступную по адресу
устройства в локальной сети (и в режиме точки доступа). Страница MUST
содержать статус устройства и форму редактирования настроек.

#### Scenario: Открытие админки по STA-адресу
- **WHEN** устройство подключено к домашней сети и пользователь открывает
  http://<ip-устройства>/ в браузере
- **THEN** загружается страница со статусом и формой настроек

#### Scenario: Открытие админки в режиме точки доступа
- **WHEN** устройство работает в режиме provisioning и пользователь подключён
  к его точке доступа
- **THEN** админка доступна по адресу 192.168.4.1

### Requirement: Статус устройства
Страница админки SHALL показывать текущее состояние: подключение Wi-Fi и IP,
валидность времени, показания датчика климата, текущий режим работы.

#### Scenario: Отображение статуса
- **WHEN** пользователь открывает админку
- **THEN** на странице видны состояние Wi-Fi, IP-адрес, статус времени,
  климат и режим устройства

### Requirement: Форма настроек
Форма админки SHALL позволять редактировать: SSID и пароль Wi-Fi, время
отбоя, окно сна, длительность вызова, часовой пояс, имена детей, токен
Telegram-бота.

#### Scenario: Форма содержит все поля
- **WHEN** пользователь открывает админку
- **THEN** форма содержит поля для всех настроек с текущими значениями
  (пароль может отображаться замаскированным)

### Requirement: Сохранение настроек
При отправке формы устройство SHALL валидировать значения, сохранять
настройки в энергонезависимую память и применять их без перепрошивки.

#### Scenario: Успешное сохранение
- **WHEN** пользователь отправляет форму с валидными значениями
- **THEN** настройки записываются в NVS, применяются к работе устройства,
  а страница подтверждает сохранение

#### Scenario: Невалидные значения
- **WHEN** форма содержит невалидные значения (например время не в формате
  ЧЧ:ММ)
- **THEN** невалидные поля не сохраняются, валидные применяются по правилам
  модуля настроек
