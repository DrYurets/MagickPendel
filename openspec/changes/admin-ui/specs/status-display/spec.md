# Spec Delta

## ADDED Requirements

### Requirement: Имена детей на экране вызова
Экран вызова SHALL отображать настроенные имена детей из настроек устройства
вместо фиксированных меток.

#### Scenario: Вызов по имени
- **WHEN** в настройках задано имя «Марк» и приходит вызов для первого
  ребёнка
- **THEN** на экране вызова крупно отображается «МАРК»
