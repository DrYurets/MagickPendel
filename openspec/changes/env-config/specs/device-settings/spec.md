# Spec Delta

## ADDED Requirements

### Requirement: Дефолты из файла окружения
При сборке прошивки значения из файла `.env` в корне репозитория SHALL
использоваться как дефолты настроек (Wi-Fi SSID/пароль, отбой, окно сна,
длительность вызова, таймзона, имена детей, токен Telegram). Сохранённые
в NVS значения MUST иметь приоритет над `.env`.

#### Scenario: Первый запуск с заполненным .env
- **WHEN** устройство прошито с заполненным `.env` и сохранённых настроек
  нет
- **THEN** применяются значения из `.env` (включая Wi-Fi — устройство
  подключается к указанной сети без режима настройки)

#### Scenario: NVS приоритетнее .env
- **WHEN** в `.env` задан SSID «A», а в NVS сохранён SSID «B»
- **THEN** устройство использует «B»

#### Scenario: Сборка без .env
- **WHEN** файл `.env` отсутствует
- **THEN** прошивка собирается и работает на встроенных дефолтах
