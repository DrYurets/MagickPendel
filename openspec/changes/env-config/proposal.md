# Proposal

## Why

Провижининг через AP-точку пока не работает на этом железе (RF-проблема
платы), поэтому Wi-Fi нельзя задать через админку на практике. Нужен
простой запасной канал конфигурации: файл окружения в корне проекта,
значения из которого подставляются дефолтами на этапе сборки.

## What Changes

- Файл `.env` в корне репозитория с константами окружения (Wi-Fi, отбой,
  окно сна, длительность вызова, таймзона, имена детей, токен Telegram).
- `settings.cpp` подхватывает значения `.env` как дефолты при первом
  запуске (до первого сохранения из админки); сохранённые в NVS значения
  по-прежнему приоритетнее.
- `.env` добавлен в `.gitignore` (секреты не коммитятся), `.env.example` —
  в репозитории как шаблон.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `device-settings`: источник дефолтов — файл окружения `.env`,
  подключаемый на этапе сборки. Базовая спека ещё не заархивирована
  (в change init-firmware) — дельта оформлена как ADDED, архивировать
  после init-firmware.

## Impact

- Новый файл `.env` (не коммитится), `.env.example` (коммитится).
- Правки в `firmware/settings.cpp` и `.gitignore`.
- Без `.env` поведение не меняется — работают встроенные дефолты.
